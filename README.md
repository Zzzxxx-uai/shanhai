## 交互与翻页

- **翻页**：左右箭头、键盘 ← →、底部进度点、目录跳转，或点击书页左右两侧的书角翘起处；
  手机与触控板上还可**左右滑动**（拖动时纸跟手，松手不足三成自动回弹）
- **仿实体书翻页**：整张纸绕书脊在 3D 空间翻起，带纸面反光、纸口投影与书脊阴影，
  单次 380ms、缓入缓出；首末页自动隐去对应箭头，翻页期间的连点只记一次
- 阅读进度自动记忆，下次打开接着看

## 声音

- **背景乐**：一段 64 秒的轻柔纯音乐（古琴式拨弦 + 和声垫，五声音阶 D 宫），
  首尾等相位的无缝循环，音量很轻，只做底
- **翻页不发声**：翻页时没有任何音效（原「翻书声」已于 2026-11-26 按要求移除）
- **播放时机**：受浏览器自动播放策略限制，背景乐在**第一次点击或滑动**后才起播，
  之后持续循环，翻页不会打断、不会从头重放
- **声音开关**：右上角喇叭按钮一键静音/恢复背景乐；
  默认开启，选择记在 `localStorage`，刷新后保持
- 音频为**程序合成**（`tools/make_audio.py`，无版权问题），mp3 + ogg 共约 0.8MB；
  页面加载时即预取解码，第一次点击就出声，不等网络

## 技术说明

- 纯原生 HTML / CSS / JavaScript，**零框架、零 CDN 依赖**，离线可运行
- 书页：CSS 3D 翻转（位移交给合成器的 `transform` 过渡，明暗只改 `opacity`，
  翻页前一次性铺好内容、不触发布局），尊重 `prefers-reduced-motion`
- 声音：WebAudio 解码后播放背景乐（增益、循环点、淡入淡出都可精确控制）；
  浏览器不允许 `file://` 页面 fetch 本地文件，离线双击打开时自动退回 `<audio>` 元素通道
- 排版：桌面左图右文，窄屏自动改上图下文，适配 iPhone 安全区
- `tools/`：场景图处理、音频合成、单文件打包、同步部署、流程自检脚本
  （`make_audio.py` 生成声音素材，`probe_sound.py` 按真实时间检查声音链路）

## 考据原则

1. 「古籍 · 白话转述」为传世文献相关记载的转述，**出处随页如实标注**（如《山海经》《庄子》《春秋》《左传》《吕氏春秋》、四象之说等），不虚构篇卷
2. 「博物 · 对照参考」为当代知识对接的合理推测，页面标注，不与古籍内容混淆
3. 少年岳及其所见所感是据记载推演的**情景化叙述，非古籍原文**，页面逐页显式标注（标注中的出处与该页「古籍」栏一致）
4. 兽名注音参考《汉语大字典》《现代汉语词典》等工具书
5. 插画为敦煌壁画重彩风格的 AI 再创作，非古代刻本原件
