# 山海舆图 · 先民观 · 有声绘本

一本**电子书绘本**：翻页即有人声讲述，水墨淡彩瑞兽图谱风格插画，宣纸纸质书页质感。
循着一位执笔少年「岳」的足迹，走过五境山海、遇见十五种神兽灵禽，读懂华夏先民敬畏自然、探索天地的精神。

> 参赛：全国大学生数字媒体科技作品及创意竞赛 · 中华优秀传统文化数字化表达赛道

## 交互与朗读

- **翻页**：左右箭头、键盘 ← →、手机左右滑动、底部进度点、目录跳转
- **人声讲述**：翻页后自动开讲，文字**逐句高亮**跟随；可暂停 / 继续，点任意一句即从该句讲起
- **设置**：讲述声音（设备内置中文语音）、语速、是否自动讲述
- 首次需点一下页面（浏览器要求用户手势才能发声），点封面「开卷」即可
- 若设备无中文语音：Windows 可在「设置 → 时间和语言 → 语音」添加中文语音包；手机系统自带
- 阅读进度自动记忆，下次打开接着看

## 人声：真人录音优先

讲述有两种来源，绘本会自动择优：

1. **真人录音优先**：`assets/js/audio-map.js` 里有该页映射时，直接播放录音，文字按音频时长自动跟随高亮
2. **合成语音兜底**：未导入录音的页，用设备内置中文语音。默认优先挑选**自然/神经网络音色**
   （如 Edge 的「晓晓 / 云希 / 云健 Online（Natural）」），并整页一次成句，避免逐句拼接的机械感；
   若引擎不派发 boundary 事件，自动退回逐句播放以保证高亮跟随

**导入录音的流程：**

1. `python tools/gen_script.py` → 生成 `录音稿.md`（25 页文稿、字数、参考时长、文件命名）
2. 按页码录音，文件放进 `shanhai/录音/`，命名如 `01.mp3`…`25.mp3`（文件名含页码即可）
3. `python tools/import_audio.py` → 自动改名归位到 `assets/audio/`，写入映射表
4. `python tools/build_standalone.py` → 录音以 base64 内嵌进单文件版，离线也能听

`python tools/import_audio.py --clear` 可一键退回合成语音。

## 背景音乐

默认是一段**本书内置合成器实时生成的古筝独奏**：D 宫五声音阶（宫商角徵羽）随机成句，
音色用 Karplus-Strong 弹拨物理建模，过了程序生成的房间混响，偶尔带一点「刮奏」装饰。
波形全部由 `assets/js/bgm.js` 实时计算产生，**不含任何第三方音乐素材，不涉及版权**，也不增加体积。

- 讲述开始时自动**压低到三成**（ducking），讲完缓慢回升
- 「设置」里可关闭，或拖动「音乐音量」调整；开关与音量会被记住
- **换成自己的曲子**：把任意 mp3 命名为 `assets/audio/bgm.mp3` 放进去即可，
  页面会自动优先播放它（此曲源自用户自行准备，需自行确认版权）；删掉该文件则回到内置合成音乐
- **注意**：浏览器不允许无交互自动播放，第一次点击/按键后音乐才会起来

## 技术说明

- 纯原生 HTML / CSS / JavaScript，**零框架、零 CDN 依赖**，离线可运行
- 讲述：Web Speech API（`speechSynthesis`）整页合成 + `onboundary` 高亮，失败自动退回逐句；
  已预留真人录音通道（`window.AUDIO`），未导入时无音频文件、完全离线
- 书页：CSS 3D 翻页动效（`rotateY` + 位移），尊重 `prefers-reduced-motion`
- 排版：桌面左图右文，窄屏自动改上图下文，适配 iPhone 安全区
- `tools/`：场景图处理、单文件打包、同步部署、录音导入、流程自检脚本

## 考据原则

1. 「古籍 · 白话转述」为传世文献相关记载的转述，**出处随页如实标注**（如《山海经》《庄子》《春秋》《左传》《吕氏春秋》、四象之说等），不虚构篇卷
2. 「博物 · 对照参考」为当代知识对接的合理推测，页面标注，不与古籍内容混淆
3. 少年岳及其所见所感是据记载推演的**情景化叙述，非古籍原文**，页面逐页显式标注（标注中的出处与该页「古籍」栏一致）
4. 兽名注音参考《汉语大字典》《现代汉语词典》等工具书
5. 插画为水墨淡彩瑞兽图谱风格的 AI 再创作，非古代刻本原件
