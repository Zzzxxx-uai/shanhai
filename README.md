# 山海舆图 · 先民观

一款以《山海经》为基底的可交互博物舆图 H5。
循着先民的足迹，在数字长卷里读懂华夏先民敬畏自然、探索天地的精神。

> 参赛：全国大学生数字媒体科技作品及创意竞赛 · 中华优秀传统文化数字化表达赛道

## 打开方式

- **单文件版**：直接双击 `山海舆图-先民观.html`（图片已内嵌，无需服务器、可离线、可直接转发）
- **工程版**：`index.html` + `assets/`，保持目录结构即可
- **压缩包**：`山海舆图-先民观.zip`，解压后双击 `index.html`

## 五层级结构

首页启卷 → 山海舆图（2.5D 视差长卷，五处地点）→ 地点知识卡（本境 3 只异兽）
→ 异兽详情（先民故事 + 四层考据）→ 时间线 → 结语回响

共 5 处地点、15 只异兽。看过的兽会盖一枚「已识」朱印，顶部实时显示「已识 N / 15」，
集齐后进度条转为朱红，结语页回响你此行所遇的每一只。

## 部署到 GitHub Pages（长期访问地址）

1. 在 GitHub 新建一个**公开**空仓库（不要勾选 README / .gitignore）
2. 在本目录执行（把 `<你的账号>/<仓库名>` 换成实际值）：
   ```bash
   git remote add origin https://github.com/<你的账号>/<仓库名>.git
   git branch -M main
   git push -u origin main
   ```
3. 仓库页面 → **Settings → Pages** → Source 选 `main` 分支、目录 `/ (root)` → Save
4. 等 1～2 分钟，地址形如 `https://<你的账号>.github.io/<仓库名>/` 即可访问

仓库里已放 `.nojekyll`，避免 GitHub 的 Jekyll 构建影响下划线开头的资源路径。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，**零框架、零 CDN 依赖**，离线可运行
- 横向长卷：`overflow-x` 原生滚动 + `transform` 视差补偿（`translateX(scrollLeft*(1-speed))`）
- 墨迹粒子：Canvas 绘制，尊重 `prefers-reduced-motion`
- 移动端适配：窄屏异兽一览改两列、异兽详情改上图下文
- `tools/`：素材压缩、单文件打包、数据与点击流程自检脚本

## 考据原则

1. 「古籍原文」为《山海经》记载的白话转述，出处只标《山海经》，不虚构卷次
2. 「博物对照」为当代知识对接的合理推测，页面标注「对照参考」，不与原文混淆
3. 「先民故事」是据记载推演的情景化叙述，**非古籍原文**，页面独立成块并显式标注
4. 兽名注音参考《汉语大字典》《现代汉语词典》等工具书
